# 2026 천안시체육회장배 인라인 스피드대회 전광판

고고인라인처럼 대회 → 종목 → 조별 결과 → 선수 카드 순으로 보는 현장용 웹앱입니다.

## 바로 쓰는 방법
1. 압축을 풀고 `index.html` 을 크롬으로 엽니다.
2. 심판실 암호 **2026**

필수 파일: index.html, app.js, data.js, app.css
